# Changelog / История версий

## 1.6.0
- EN: three window layouts — the setting "View" or `/view`: classic (the default, unchanged), **messenger** (a second line with the latest message or your draft under every chat, messages grouped by author, a "new messages" line) and **two panes** (two chats side by side, open chats as tabs, `Ctrl+←` / `Ctrl+→` or `F8` switch the pane, `Ctrl+W` closes a tab); `Ctrl+K` quick switcher for chats and commands (works on the wrong keyboard layout too); `Ctrl+N` / `/next` jumps to the next chat with unread messages, mentions first; `Alt+1` … `Alt+9` open pinned chats; `/mute`, `/dnd [minutes]` and the setting "Quiet hours" (muted chats, including those muted in Telegram, make no sound or notification and are left out of the unread total); `/drafts` lists chats with unsent text; link cards under messages; a text longer than 4096 characters is split into several messages by itself (paragraph, line, sentence, word; code blocks stay closed), and unsent parts return to the right chat; `/export [txt|md|html|json]`; photos are shrunk before sending (setting "Shrink photos on send", on by default; JPEG and PNG, at most 2048 px, phone rotation kept, original untouched); `F7` offers only actions that can work for the selected message (no more "open" that ends in an error; `O` is "listen", "watch" or "open" by file type); `/report` now has the Windows name, version, edition and build, architecture, processor, memory, disk space, terminal, Windows components, network state, settings and the program folder, still without messages, passwords, phone numbers, the Windows user name or proxy addresses; the help window (`F1`) is rewritten: it wraps long lines, scrolls on small consoles and lists every command (the old one cut its last line and part of the descriptions in a 30-row console). A full audit of this version also fixed: a crash when a poll came with huge or inconsistent vote numbers; several cases where the screen could get out of step with the chat list (the chat picker, forwarding, the jump to a found message and opening a chat that had just disappeared); a damaged or oversized picture can no longer crash the preview (a JPEG header that promises gigabytes is refused, PNG is limited to 25 million pixels, a broken picture is drawn as a black frame); one unreadable setting no longer makes the vault refuse to open, the other settings are kept; a failed save of the settings and the session to disk is now shown in the status line instead of staying silent; Windows helper programs (`rundll32`, `clip`, `reg`, `powershell`) are started by full path from the system folder, write nothing into the program window, and links with a quote in them are not passed on; the bot token in the release workflow is given only to the steps that need it; the README no longer says that photos are not decoded; the tests now draw every view and mode at every console size and feed the program a long series of random keys, mouse clicks and server events.
- RU: три вида окна — настройка «Вид» или `/view`: классический (по умолчанию, без изменений), **мессенджер** (под каждым чатом вторая строка с последним сообщением или вашим черновиком, сообщения сгруппированы по авторам, строка «новые сообщения») и **два окна** (два чата рядом, открытые чаты вкладками, `Ctrl+←` / `Ctrl+→` или `F8` переключают окно, `Ctrl+W` закрывает вкладку); быстрый переход `Ctrl+K` по чатам и командам (находит и при неверной раскладке); `Ctrl+N` / `/next` — к следующему чату с непрочитанными, сначала с упоминаниями; `Alt+1` … `Alt+9` открывают закреплённые чаты; `/mute`, `/dnd [минуты]` и настройка «Тихие часы» (заглушённые чаты, в том числе заглушённые в Telegram, не звучат, не всплывают и не входят в число непрочитанных); `/drafts` — чаты с неотправленным текстом; карточки ссылок под сообщениями; текст длиннее 4096 знаков сам делится на несколько сообщений (по абзацу, строке, предложению, слову; блоки кода остаются закрытыми), а неотправленные части возвращаются в нужный чат; `/export [txt|md|html|json]`; фото сжимаются перед отправкой (настройка «Сжимать фото при отправке», по умолчанию включена; JPEG и PNG, не больше 2048 точек, поворот снимка сохраняется, исходный файл не меняется); `F7` предлагает только то, что сработает для выбранного сообщения (больше нет «открыть», которое заканчивается ошибкой; `O` — «слушать», «смотреть» или «открыть» по типу файла); в `/report` теперь название, версия, редакция и сборка Windows, разрядность, процессор, память, место на диске, терминал, компоненты Windows, состояние сети, настройки и папка программы, по-прежнему без сообщений, паролей, номеров телефонов, имени пользователя Windows и адресов прокси; окно справки (`F1`) переписано: переносит длинные строки, листается на маленьких консолях и перечисляет все команды (старое обрезало последнюю строку и часть описаний в консоли на 30 строк). Полный аудит версии также исправил: падение, когда опрос приходил с огромными или противоречивыми числами голосов; несколько случаев, когда экран расходился со списком чатов (выбор чата, пересылка, переход к найденному сообщению и открытие только что исчезнувшего чата); повреждённая или огромная картинка больше не роняет просмотр (JPEG, в заголовке которого обещаны гигабайты, отклоняется, PNG ограничен 25 миллионами точек, битая картинка рисуется чёрным кадром); один нечитаемый параметр настроек больше не мешает открыть хранилище, остальные настройки сохраняются; неудачное сохранение настроек и сессии на диск теперь видно в строке состояния, а не остаётся молчаливым; вспомогательные программы Windows (`rundll32`, `clip`, `reg`, `powershell`) запускаются по полному пути из системной папки, ничего не пишут в окно программы, а ссылки с кавычкой им не передаются; токен бота в сценарии выпуска выдаётся только тем шагам, которым он нужен; в README больше нет утверждения, что фото не декодируются; в тестах теперь рисуется каждый вид и режим при каждом размере консоли, а программе скармливается длинная серия случайных клавиш, щелчков мышью и событий сервера.

## 1.5.0
- EN: settings are grouped into sections (Security, Connection, Messages and sound, Appearance, General); `/album` sends 2–10 photos as one message; `T` in `F7` reads a text file (txt, md, log, json, csv, xml, yml, toml, ini, up to 1 MB) in a window; `Ctrl+Z` / `Ctrl+Y` undo and redo in the input; Windows notifications (setting, off by default, never show message text); simple emoji are shown in Windows Terminal (setting "Emoji in text": auto, always, never); `/netcheck` tests every route and data center and names the one that works; `/report` saves a text for bug reports without phone numbers and message text; the `F7` hint offers `O` for voice, music and video.
- RU: настройки собраны в разделы (Защита, Подключение, Сообщения и звук, Внешний вид, Общие); `/album` отправляет 2–10 фото одним сообщением; `T` в `F7` читает текстовый файл (txt, md, log, json, csv, xml, yml, toml, ini, до 1 МБ) в окне; `Ctrl+Z` / `Ctrl+Y` — отмена и повтор в поле ввода; уведомления Windows (настройка, по умолчанию выключено, текст сообщений не показывается); в Windows Terminal показываются простые эмодзи (настройка «Эмодзи в тексте»: авто, всегда, никогда); `/netcheck` проверяет каждый путь и дата-центр и называет рабочий; `/report` сохраняет текст для сообщения об ошибке без номеров телефонов и текста сообщений; в подсказке `F7` для голосовых, музыки и видео есть `O`.

## 1.4.0
- EN: the status line shows the connection (`● 42 ms` / `○ no connection`); messages sent without network wait in a queue (up to 30) and go out by themselves, in order, when the connection returns; marking several messages with `Space`, `Shift+↑/↓` or by dragging the mouse (the conversation scrolls by itself when the pointer is held at the top or bottom edge, `Ctrl`+click marks one) and forwarding, deleting or copying them all at once; polls are shown with percentages and `V` votes; `/topics` lists forum topics and sends your messages into the chosen one; `P` shows a photo in the console with colored half-blocks; `Ctrl+V` with a screenshot on the clipboard sends it as a photo; fixed: the exe was not attached to the Telegram channel post (the `@` in the channel name was read by curl as a file).
- RU: в строке состояния видна связь (`● 42 мс` / `○ нет связи`); сообщения, отправленные без сети, ждут в очереди (до 30) и уходят сами, по порядку, когда связь вернётся; отметка нескольких сообщений `Пробелом`, `Shift+↑/↓` или протягиванием мыши (переписка листается сама, когда указатель у верхнего или нижнего края, `Ctrl`+щелчок отмечает одно) и пересылка, удаление или копирование всех сразу; опросы показываются с процентами, `V` — голосовать; `/topics` показывает темы форума и отправляет ваши сообщения в выбранную; `P` показывает фото в консоли цветными полублоками; `Ctrl+V` со скриншотом в буфере обмена отправляет его как фото; исправлено: exe не прикреплялся к посту в Telegram-канале (`@` в имени канала curl читал как файл).

## 1.3.1

- RU: новая иконка (пузырь чата с командной строкой) для exe, README и репозитория; уведомление теперь короткий мягкий щелчок через системный звук (старый писк остаётся запасным вариантом); в Telegram → Настройки → Устройства сеанс называется `Tg-Lite v1.3.1 (Windows)` вместо `Windows 64-bit`, а версия приложения настоящая, а не версия библиотеки.

## 1.3.0
- EN: reactions under messages (short words such as `+1 3`, yours in brackets; `1`–`6` in `F7` set one, the same digit or `0` removes it); `G` in `F7` jumps to the original of a reply and `B` goes back; buttons of bot messages are shown and pressed from the `K` list (Enter or a digit; link buttons open in the browser); after three wrong passwords the lock screen asks you to wait 5, 10, 20 … seconds (up to 5 minutes); day separators say "Yesterday"; new setting "Theme" (dark, light, high contrast, Solarized).
- RU: реакции под сообщениями (короткие слова вроде `+1 3`, ваша в скобках; `1`–`6` в `F7` ставят реакцию, та же цифра или `0` снимает); `G` в `F7` переходит к оригиналу ответа, `B` возвращает; кнопки сообщений ботов показываются и нажимаются из списка `K` (Enter или цифра; кнопки-ссылки открываются в браузере); после трёх неверных паролей экран блокировки просит подождать 5, 10, 20 … секунд (до 5 минут); в разделителях дней есть «Вчера»; новая настройка «Тема» (тёмная, светлая, высокий контраст, Solarized).

## 1.2.0
- EN: read marks in private chats (`√` sent, `√√` read); `/pinned` lists all pinned messages; `/chat @name` opens a chat by public name (also people you have never written to); `/join` joins by invite link or public name; `/leave` leaves a group or channel after a repeated command; cloud drafts (unsent text is saved in Telegram when you switch chats or stop typing, drafts typed on the phone appear here; new setting "Cloud drafts", on by default; commands are never uploaded); view counts next to channel posts.
- RU: отметки прочтения в личных чатах (`√` отправлено, `√√` прочитано); `/pinned` — список всех закреплённых сообщений; `/chat @имя` открывает чат по публичному имени (в том числе с тем, кому вы не писали); `/join` — вступление по ссылке-приглашению или публичному имени; `/leave` — выход из группы или канала после повторной команды; облачные черновики (неотправленный текст сохраняется в Telegram при смене чата или паузе в наборе, черновики с телефона появляются здесь; новая настройка «Облачные черновики», по умолчанию включена; команды не отправляются); просмотры рядом с постами каналов.

## 1.0.1
- EN: `/open` (O in F7) opens an attachment with the default Windows program (pictures, PDF, text, audio, video up to 50 MB; temporary `tglite-view` folder is emptied on lock, exit and start); `/copy` (C in F7) copies message text; input history on Alt+Up / Alt+Down (and Up / Down when the input has text); HTTP proxies with a login (`/proxy user:password@host:port`), the password is hidden on screen and in the log; more tests; CI: actions updated to Node 24 versions, dependency `pulldown-cmark` updated (security advisory RUSTSEC-2026-0433).
